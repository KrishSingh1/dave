# LPJ-Guess DAVE

DAVE (**D**ynamics of **A**ustralian **VE**getation) is a fork of LPJ-GUESS, a
dynamic global vegetation model, used for simulating Australian ecosystems.

Full documentation is available at the
[DAVE documentation site](https://pages.stormbringer4.nateko.lu.se/dave/lpj-guess-dave/).
