# LPJ-GUESS DAVE

DAVE (**D**ynamics of **A**ustralian **VE**getation) is a fork of LPJ-GUESS, a dynamic global vegetation model (DGVM), used for simulating Australian ecosystems.

This documentation site is the central reference for running, developing, and understanding the DAVE fork.

## What you'll find here

- [**Science documentation**](science/index.md) for model behaviour and process details.
- [**How-to guides**](howto/index.md) for setup and execution workflows.
- [**Project context**](development/index.md) for developers working on the DAVE codebase.

## Scope of this docs site

The docs focus on the DAVE fork and workflows commonly used in this repository (including OzFlux site simulations and debugging/development workflows).

As the site grows, additional pages for Linux/macOS setup, run configuration, outputs, and developer internals will be added under the existing sections.
