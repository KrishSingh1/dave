LPJ-GUESS Version 2002-01-24 : Setup to run under Windows as a DLL
==================================================================

This file explains how to set up LPJ-GUESS as a dynamic link library to run
under the LPJ-GUESS Windows Shell.

You require ALL the files in this directory, as well as the source code files
in directories ../modules and ../framework. Read carefully the file "readme.txt"
in the parent directory to this one if you have not already done so.

Full instructions are given in the following files in this directory:

For installation in Microsoft Visual C++ / Developer Studio Version 6:
     guess_installhelp_ds6.PDF

For installation in Microsoft Visual C++ / Visual Studio .NET:
     guess_installhelp_vsnet.PDF
